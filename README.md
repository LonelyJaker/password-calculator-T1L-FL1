## 📖 使用说明

### 基本操作

1. **设置SOP时间**
   - 在输入框中输入8位数字的日期（格式：YYYYMMDD）
   - 或点击📅图标使用可视化日历选择日期
   - 默认值为：20250930

2. **计算密码**
   - 点击"🔢 计算密码"按钮
   - 或在输入框中按回车键
   - 系统将立即计算并显示所有密码

3. **复制密码**
   - 点击每个密码卡片右上角的"📋 复制"按钮
   - 密码将自动复制到剪贴板
   - 按钮会显示"✓ 已复制"确认

4. **自动更新**
   - 系统每小时自动重新计算一次
   - 状态栏显示下次更新时间
   - 无需手动干预

### 密码类型说明

#### 🏭 工程模式动态密码
- **用途**: 蓝牙电话进入使用
- **计算公式**: `(用户SOP时间 × 当前时间MMDDHH - 当前小时数)` 的最后六位
- **特点**: 基于用户自定义的SOP时间，可随时修改

#### 🔑 8155加密区动态密码
- **用途**: 工程模式内使用
- **计算公式**: `(固定SOP 20240910 × 当前时间MMDDHH)` 的最后六位
- **特点**: 基于固定SOP时间，不可修改

#### 🔑 8255加密区动态密码
- **用途**: 工程模式内使用
- **计算公式**: `(固定SOP 20250830 × 当前时间MMDDHH)` 的最后六位
- **特点**: 基于固定SOP时间，不可修改

## 🔧 计算规则详解

### 时间格式说明
- **SOP时间格式**: `YYYYMMDD`（8位数字）
  - 例如：2025年9月30日 → `20250930`
  
- **当前时间格式**: `MMDDHH`（6位数字）
  - MM: 月份（01-12）
  - DD: 日期（01-31）
  - HH: 小时（00-23）
  - 例如：9月30日15时 → `093015`

### 计算示例

假设：
- 用户SOP时间 = `20250930`
- 当前时间 = `093015`（9月30日15时）
- 当前小时数 = `15`

#### 工程模式动态密码
```
步骤1: 20250930 × 093015 = 1883578989950
步骤2: 1883578989950 - 15 = 1883578989935
步骤3: 取最后六位 = 989935
结果: 989935
```

#### 8155加密区动态密码
```
步骤1: 20240910 × 093015 = 1883023153650
步骤2: 取最后六位 = 153650
结果: 153650
```

#### 8255加密区动态密码
```
步骤1: 20250830 × 093015 = 1883528694950
步骤2: 取最后六位 = 694950
结果: 694950
```

## 🐛 故障排除

### 常见问题

**Q: 密码显示为 `------`**
- A: 请检查SOP时间格式是否正确（8位数字）
- A: 点击"计算密码"按钮重新计算

**Q: 复制功能不工作**
- A: 请确保浏览器支持 Clipboard API
- A: 某些浏览器需要HTTPS环境才能使用复制功能

**Q: 日历选择器位置不正确**
- A: 调整浏览器窗口大小后会自动重新定位
- A: 尝试滚动页面或刷新浏览器

**Q: 密码没有自动更新**
- A: 检查浏览器是否进入休眠模式
- A: 刷新页面重新激活自动更新
